# OSBB

One shared conversation: five co-owners of an apartment building talk with each
other and with the agent that answers for their association, on a single
replayable session.

An [OSBB](https://uk.wikipedia.org/wiki/Об%27єднання_співвласників_багатоквартирного_будинку)
is a Ukrainian condominium association — the co-owners of one building acting
together. The agent speaks for it. In the default scenario two co-owners report
the same night noise from different apartments, and the association answers
both without merging their accounts.

This example exists to make Agentyk's multi-actor contract visible. Each
co-owner's input is a `Message` carrying an `ExternalActor`; the event log keeps
the original text and identity, while the model sees speaker labels such as
`[Olena]` and `[Petro]`.

## Run it

```sh
export OPENAI_API_KEY=...
cargo run --release -p osbb
```

Defaults are intentionally ready for the demo:

```text
One shared conversation between a building's co-owners and their association.

Usage: osbb [OPTIONS]

Options:
      --people <PEOPLE>                      Co-owners allowed to speak
                                             [default: Olena,Petro,Iryna,Mykola,Sofia]
      --actor <ACTOR>                        Co-owner selected when the conversation opens
      --agent-name <AGENT_NAME>              Agent answering for the association
                                             [default: Manager]
      --building <BUILDING>                  Building the association manages
                                             [default: "Sadova 12"]
      --model <MODEL>                        OpenAI model id [default: gpt-5.6-terra]
      --base-url <BASE_URL>
      --reasoning-effort <REASONING_EFFORT>  [default: none]
      --log <LOG>
  -h, --help
  -V, --version
```

Inside the conversation:

```text
/as NAME  speak as another co-owner
/who      show everyone in the conversation
/help     show help
/quit     leave the conversation
```

Plain text belongs to the currently selected co-owner. OSBB rejects unknown
names instead of silently creating participants.

The association's standing instructions — the house rules it cites, and the
limits on what it may promise — live in `system_prompt`. Quiet hours, warning
before escalation, and "only the general meeting decides that" are prompt
content, not library behavior.

## What it proves

- Five named co-owners append to one `Session`, so each turn sees the full
  shared history — including what a neighbour said two turns ago.
- `ExternalActor { source, actor_id, actor_name }` survives event-log replay.
- Provider-facing context labels each user without rewriting the durable
  message.
- The UI has no participant database. Membership, roles, and authorization
  remain responsibilities of an embedding host such as Everruns.

The offline test walks two of the co-owners through the real executor with
`SimDriver` and inspects both raw history and recorded model requests:

```sh
cargo test -p osbb
```

## Re-recording the demo

[`demo.tape`](demo.tape) drives a real `gpt-5.6-terra` run: Olena reports the
noise, Petro confirms it from another apartment, and Iryna asks what happens
next. Record with [VHS](https://github.com/charmbracelet/vhs) and compress with
[gifsicle](https://www.lcdf.org/gifsicle/):

```sh
cargo build --release -p osbb
PATH="$PWD/target/release:$PATH" OPENAI_API_KEY=... vhs examples/osbb/demo.tape
gifsicle -O3 --lossy=60 --colors 64 -b examples/osbb/docs/demo.gif
```

The tape records at 2× density and this README displays the result at half
width, matching Codenko's sharp HiDPI demo convention.
